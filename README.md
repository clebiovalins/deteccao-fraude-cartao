# detecção-fraude-cartao
você treina modelos em Python para detectar fraude em transações reais de cartão de crédito, um problema em que só 0,17% dos casos são fraude e a acurácia engana. Com pandas, NumPy e scikit-learn, você prepara os dados, compara regressão logística, Random Forest e XGBoost pelo recall da fraude, ajusta o limiar de decisão e explica o modelo com SHAP
